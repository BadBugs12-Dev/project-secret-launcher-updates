# Project Secret Launcher updates

Official public update feed for Project Secret Launcher.

The launcher reads latest.json, downloads the versioned launcher executable over HTTPS, and verifies its SHA-256 and version before applying it.

Manifest: https://raw.githubusercontent.com/BadBugs12-Dev/project-secret-launcher-updates/main/latest.json

Release packages: https://github.com/BadBugs12-Dev/project-secret-launcher-updates/releases

Only release packages and update metadata are published here.
